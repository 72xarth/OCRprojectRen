📌 คู่มือการใช้งานระบบ (เวอร์ชันใหม่ + Editor แบบต่อเนื่อง)

  • 📤 เลือกหรือลากวางไฟล์ PDF ที่ต้องการแปลงเป็นข้อความ
  • 📑 เลือกหน้าที่ต้องการแปลง 4 วิธี: ทุกหน้า / ช่วงหน้า / พิมพ์ระบุ / คลิกเลือก
  • 🚀 กดปุ่ม "เริ่มแปลงหน้าที่เลือก" และดูความคืบหน้าแบบเรียลไทม์
  • ✏️ Editor เปิดอัตโนมัติ! หน้าจอแบ่ง 2 ฝั่ง:
    • 📄 ฝั่งซ้าย = ข้อความต้นฉบับจาก OCR (อ่านอย่างเดียว)
    • ✏️ ฝั่งขวา = Editor (เริ่มเป็นหน้าว่าง พร้อมแก้ไข)
  • 👈 คัดลอกต้นฉบับ: กดปุ่ม "คัดลอกต้นฉบับ" (สีเขียว) เพื่อเอาข้อความจากซ้ายมาแก้ไข
  • 🎨 ใช้เครื่องมือ Editor: ตัวหนา (B), ตัวเอียง (I), ขีดเส้นใต้ (U), เปลี่ยนขนาด, เปลี่ยนฟอนต์, เปลี่ยนสี
  • 📄+ OCR หน้าอื่นต่อ (ใหม่!): กดปุ่ม "OCR หน้าอื่นต่อ" (สีฟ้า) เพื่อเลือก OCR หน้าอื่นเพิ่ม โดย:
    • ✅ Editor ของคุณถูกบันทึกไว้อัตโนมัติ
    • ✅ OCR หน้าใหม่เสร็จ → Editor กลับมาพร้อมข้อความเดิม
    • ✅ ทำงานต่อเนื่องได้โดยไม่ต้องกังวล
  • 💾 บันทึกพร้อมฟอนต์: ดาวน์โหลด Word จะบันทึก TH Sarabun New (26px) พร้อมการจัดรูปแบบ
  • 📋 คัดลอกข้อความที่แก้ไขแล้วจาก Editor หรือดาวน์โหลดเป็น Word/TXT
  • 🔄 กดปุ่ม "รีเซ็ต" ใน Editor เพื่อเคลียร์เป็นหน้าว่างใหม่
  • ✕ ปิดหน้าเกริ่นนำ: กดปุ่ม "✕ ปิด" (สีแดง) เพื่อปิดข้อมูลเกริ่นนำ
  • 🔍 ใช้ช่องค้นหาเพื่อค้นหาข้อความในเอกสารฝั่งซ้าย
  • 💬 เปิด "โหมดถาม-ตอบ" เพื่อไฮไลท์คำว่า "ถาม" (เหลือง) และ "ตอบ" (เขียว)
  • 📘 ดาวน์โหลดผลลัพธ์เป็น Word (.doc) หรือ Text (.txt)
  • ↻ กด "เริ่มใหม่" เพื่อ reset ทุกอย่างรวมถึง Editor
